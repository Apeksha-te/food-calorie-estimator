About the Project

AI-Based Food Calorie Estimator Using Image Processing and Machine Learning

Abstract

The AI-Based Food Calorie Estimator is a final-year engineering mini project that leverages Convolutional Neural Networks (CNN) and image processing techniques to automatically identify food items from photographs and estimate their nutritional content including calories, protein, carbohydrates, and fat.

The system uses MobileNetV2 transfer learning pre-trained on ImageNet, fine-tuned on the Food-101 dataset enriched with Indian cuisine categories (Dosa, Idli, Biryani, Samosa). The backend is built with Python Flask, image preprocessing via OpenCV, and the frontend employs a modern glassmorphism UI using Bootstrap 5.

The project achieves ~95% classification accuracy on test data and provides a complete end-to-end web application with prediction history stored in SQLite and health recommendations personalised per food class.

Objectives

  • Develop an AI system for automatic food recognition from images
  • Build and train a CNN model using transfer learning (MobileNetV2)
  • Estimate nutritional values (calories, protein, carbs, fat) per food
  • Create a user-friendly web interface for real-time food analysis
  • Store prediction history and enable daily calorie tracking
  • Provide personalised health recommendations based on food choices
  • Support Indian cuisine alongside international food categories

Modules

  • Image Acquisition: Upload from device or webcam capture
  • Image Preprocessing: Resize (224×224), blur, normalise via OpenCV
  • Feature Extraction: MobileNetV2 convolutional layers
  • Food Classification: Softmax output over 10 food classes
  • Nutrition Lookup: Curated nutritional database per class
  • History & Tracking: SQLite storage with daily totals
  • Report Generation: PDF export via ReportLab

Viva Questions & Answers

A CNN is a class of deep neural network inspired by the visual cortex. It uses convolutional layers to automatically learn spatial hierarchies of features from images — edges → textures → patterns → objects — making it ideal for image classification tasks like food recognition.

Transfer learning uses a pre-trained model's learned weights as a starting point for a new task. We used MobileNetV2 pre-trained on ImageNet (1.2M images, 1000 classes). Since lower layers learn universal features (edges, textures), we only need to re-train the top classification layers — saving time, GPU resources and achieving high accuracy with less data.

MobileNetV2 uses depthwise separable convolutions which drastically reduce parameters (~3.4M vs VGG16's 138M) while maintaining good accuracy. It is lightweight, fast for inference, and suitable for deployment on low-resource systems like a Flask server or mobile device — ideal for a web-based application.

OpenCV handles image preprocessing: (1) reading the image from disk, (2) resizing to 224×224 pixels as required by MobileNetV2, (3) applying Gaussian blur for noise removal, (4) converting BGR colour space to RGB (OpenCV reads as BGR by default), and (5) normalising pixel values from [0,255] to [0,1] for neural network input.

We used the Food-101 dataset (101 categories, ~1,000 images per class = 101,000 images total) filtered to our 10 target classes, supplemented with Indian food images scraped/collected for Dosa, Idli, Biryani, and Samosa. Data augmentation (rotation, flip, zoom, shift) was applied to increase diversity.

The model achieves approximately 93-96% validation accuracy after two-phase training: Phase 1 (frozen base, 20 epochs) reaches ~90% and Phase 2 (fine-tuning top 30 base layers, 10 epochs with lower LR) improves to ~95%. The confidence score shown in the UI reflects the softmax probability of the predicted class.

Nutritional values are stored in a curated Python dictionary (predict.py / NUTRITION_DB) with average values sourced from USDA FoodData Central and Indian food composition tables published by NIN (National Institute of Nutrition, Hyderabad). Values represent one average serving of the food. A real production system would query a live nutritional API like Edamam or Nutritionix.

Data augmentation synthetically increases the training set size by applying random transformations (rotation, horizontal flip, width/height shift, zoom, shear) to existing images. This prevents overfitting — the model learns to be invariant to these transformations — and improves generalisation to real-world photos taken from different angles and lighting conditions.
